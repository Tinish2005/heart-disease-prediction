# ❤️ Heart Disease Prediction System

A Machine Learning web application built with Streamlit that predicts the likelihood of heart disease based on patient health parameters.

## 🚀 Features

* Interactive Streamlit web interface
* Heart disease risk prediction
* Data preprocessing and feature scaling
* Machine Learning model using K-Nearest Neighbors (KNN)
* Real-time predictions

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn
* Joblib/Pickle

## 📊 Dataset

The project uses a Heart Disease dataset containing medical attributes such as:

* Age
* Sex
* Chest Pain Type
* Blood Pressure
* Cholesterol
* Maximum Heart Rate
* Exercise Induced Angina
* And other clinical parameters

## 🤖 Model

Model Used:

* K-Nearest Neighbors (KNN)

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Tinish2005/heart-disease-prediction.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run heart_disease_app.py
```
